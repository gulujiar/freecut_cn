# 慕课序列编辑

FreeCut 里的慕课模式，用来把一节课排成：可配置片头、按字幕分句的正文、可配置片尾。正文每次只有一个机位：纯 PPT、大课件加人像小窗、课件加讲师半身。它编进现有时间线，预览和成片导出走原来的播放器与 WebCodecs，不是另一套画出来的假播放。

## 环境与运行

需要 Node.js 18 或更新版本，以及 Chrome 或 Edge 113+。完整预览和导出依赖 WebGPU、WebCodecs 和 OPFS。

```bash
npm install
npm run dev
```

浏览器打开 http://localhost:5173 。新建或打开一个工程，在工具栏点「慕课序列」。空工程会放入标明「示例」的课件、背景、讲师静帧和程序生成的旁白。已有片段的工程会先询问是否用慕课编译结果替换时间线。

常用检查：

```bash
npm run test:run -- src/features/mooc
npm run build
```

## 怎么用

1. 片头、片尾的标题和秒数在右侧「当前块」里改。改片头时长时，后面的字幕会一起平移，讲课内容相对旁白的位置不变。
2. 时间轴上，字幕行下面有三行机位。点某一句下面的格子，只切换这一句，另外两行关掉，播放头若不在这一句里会跳进去，预览用编译后的真实画面更新。
3. 空格播放或暂停。1、2、3 切换播放头所在那一句的机位。焦点在输入框、文本框或下拉框里时，这些键不抢焦点。
4. 片头、片尾和字幕之间的空隙不能切机位。
5. 背景是一整层固定几何，三个机位只移动课件和讲师，避免底图跳动。
6. 「素材」页可以把本地音频、讲师视频或图片、课件图片交给现有素材库，也可以直接选用素材库里已有的条目。
7. 导入 SRT 时，时间按讲课相对时间读取，再加上片头偏移。空隙保留。重叠、时间颠倒或格式错误会整份拒绝，工程里原来的序列不动。
8. 导入或导出 XML 使用 `docs/mooc-sequence-xml.md` 里的 FreeCut 慕课序列 XML 1.0。它不是 Premiere，也不是 Final Cut 的工程格式。
9. 成片用工具栏原来的「导出视频」。导出的是编译后的时间线。
10. 「标准时间线」回到原来的多轨界面，可以看到编译出来的轨道。再回到慕课模式时，会按慕课文档重新编译。

保存工程时，慕课文档和编译后的时间线一起写入本地 IndexedDB。重新打开会载入文档并再次编译。

## 已实现

- 片头、按字幕分句的正文、片尾，片头时长可调并带动字幕偏移。
- 三行互斥机位。点选只改当前字幕，预览走现有合成。
- 字幕行在机位之上，旁白波形在最下。有音频就解码真实峰值；没有音频就写明不画波形。示例旁白是写进素材库的 PCM WAV，波形来自解码，并标明示例。
- 讲师视频是一整段，用关键帧改位置和透明度，旁白也是一整段，切换机位不断开它们。示例讲师是静帧，界面写明不是视频。
- 共享背景几何固定。
- SRT 导入处理边界、空隙和片头偏移。
- XML 往返标题、时间、包装时长和素材引用、字幕文本、机位、课件序号。属性与文本按 XML 转义。
- 畸形 XML/SRT、非有限数、负数、结束不晚于开始、重叠、重复 id 会整份拒绝，不改掉当前序列。
- 序列写入工程并在重新打开时加载。
- 视频导出使用现有导出器，不另造一条渲染管线。

## 尚未实现

- 没有数字人生成，也没有口型驱动。示例讲师是静帧。
- 机位之间是硬切，没有转场。
- 不生成、也不导入 Premiere、Final Cut、AAF 或 EDL。
- 慕课模式下在预览里拖动变换手柄，会临时改到编译片段；下一次改字幕或机位会按文档重新编译并覆盖这些拖动。
- 标准时间线里的撤销，可能和慕课文档不一致。改机位请留在慕课模式里。
- 播放器在最后一段素材之后仍会多留几秒空尾，这是原预览器的行为。慕课时间轴的片尾以文档时长为准。
- 示例 WAV 能否被某次导出的音频编码器接受，取决于浏览器的 WebCodecs 支持，和普通音频素材相同。若导出失败，换成素材库里的 AAC 或 MP3 旁白。
- 没有把慕课文档做成独立的云端课程包，也没有自动语音转写。转写仍使用 FreeCut 原来的本地转写，再把结果整理成 SRT 导入。
